# news-image-20261121

One picture summing up Saturday 21 November 2026, laid out like a front
page: six panels for six stories. Trump, Xi and Putin sit down together
in Shenzhen. A Russian missile lands in Poland. Tankers burn in the
Strait of Hormuz. AI shares sell off and the markets slide into
correction. The climate talks stall over fossil fuels. The court in The
Hague rules on Myanmar and the Rohingya.

The picture is entry.png, 1024 by 1024 pixels and under a megabyte. The
program main.py copies it to /output/entry.png and checks the copy
matches, with no network and no randomness.

To run it: python3 main.py
